# AGENTS.md

Roles for **Fountain-Coach/swift-lilypond**.

- **Maintainers:** API surface, roadmap, semver.
- **Release Engineering:** build from GitLab releases; produce self‑contained binaries; publish checksums and provenance.
- **Licensing & Compliance:** GPL obligations; license texts; source‑offer.
- **Security:** CVE tracking; artifact verification; reproducible builds.
- **Quality Engineering:** tests and golden artifacts; regression corpus.
- **Documentation:** README, troubleshooting, and examples; interop notes with sibling repos (`swift-csound`).

**Process:** trunk‑based development; Conventional Commits; semantic versioning; backports only for security/critical fixes.
