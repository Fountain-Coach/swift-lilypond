Source Offer (GPL Compliance)
=============================

We redistribute LilyPond binaries as part of our Swift Package binary artifact bundle. In accordance with the GPL, we offer the corresponding source for the exact version used.

For LilyPond v2.24.4:

- Upstream source tarball: https://gitlab.com/lilypond/lilypond/-/archive/v2.24.4/lilypond-v2.24.4.tar.gz
- We also attach this tarball to our GitHub release assets for convenience.
- See checksums in PROVENANCE.md for verification.

How to obtain the source:

- Preferred: download the attached tarball from the GitHub Release matching your package version.
- Alternative: use the upstream URL above.
- If neither is available, open an issue in this repository requesting the source for your version and we will provide it promptly.

Note: We are not affiliated with the LilyPond project owners. We use their publicly available releases under the GPL.
